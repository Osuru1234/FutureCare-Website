# FutureCare — Revolutionizing Childcare with Future Innovation

A responsive front-end website concept for a proposed community childcare innovation project in Kakuma Refugee Camp, Turkana County, Kenya.

## Files
- `index.html` — website content and structure
- `style.css` — responsive design and layout
- `script.js` — mobile navigation and automatic footer year

## Run locally
1. Open this folder in Visual Studio Code.
2. Open `index.html`.
3. If Live Server is installed, right-click `index.html` and select **Open with Live Server**.
4. Otherwise, open `index.html` directly in a browser.

## Important notes
- This is a front-end demonstration website. It does not have a server, database, login, attendance storage, or real contact form.
- The project is marked as proposed. Partner names, contact details, and implementation claims should only be added after they are confirmed.
- Before collecting any information about children, obtain appropriate consent, establish safeguarding procedures, and protect personal data.
- Google Fonts are optional; if internet access is unavailable, the site falls back to system fonts.
